# 🩺 Tuberculosis Detection Using Deep Learning

An AI-powered system for the **automated detection of Tuberculosis (TB)** from **chest X-ray images** using deep learning. Built with CNNs, deployed via Streamlit, and hosted on AWS for real-time access.

## 🚀 Project Overview

### 🎯 Objective

To build and deploy a deep learning-based binary classifier that can distinguish between **normal** and **TB-affected** chest X-ray images, enhancing early diagnosis and remote screening capabilities.

---

## 💡 Motivation

Tuberculosis is a life-threatening yet curable disease when detected early. In resource-limited settings, **AI-assisted diagnostics** can help reduce the burden on radiologists and speed up treatment decisions.

---

## 📈 Business Use Cases

- 🏥 **Early TB Detection** in clinics and hospitals
- 📡 **Remote Screening** via cloud-based systems
- 🧪 **Medical Research**: Pattern analysis & trend discovery
- 📉 **Reduce Human Errors** in diagnosis

---

## 🧠 Problem Statement

Develop a robust ML pipeline to:

- 🧼 Preprocess and augment medical image data  
- 🤖 Train CNNs and fine-tuned transfer learning models  
- 📊 Evaluate with clinically relevant metrics  
- 🖥️ Serve predictions through a web-based interface  
- ☁️ Deploy model using AWS for public access

---

## 🔬 Dataset Overview

- 📦 Source: [Kaggle - Tuberculosis Chest X-rays](https://www.kaggle.com/datasets/yasserhessein/tuberculosis-chest-x-rays-images)
- **Classes**: 
  - `TB Positive` → 2,494 images  
  - `Normal` → 514 images
- Data Split: Train / Validation / Test
